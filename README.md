# Taller Pro

App web para taller de reparación de celulares y venta de accesorios: ventas con factura, inventario con descuento automático, reparaciones, tickets térmicos, logo del negocio y avisos.

## Publicar con GitHub Pages
1. Sube `index.html` a un repositorio nuevo.
2. Settings → Pages → Source: *Deploy from a branch* → rama `main`, carpeta `/ (root)` → Save.
3. En 1–2 minutos queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Importante
- Los datos se guardan en el navegador de cada dispositivo (localStorage). No se sincronizan entre teléfono y PC.
- Usa **Ajustes → Descargar respaldo** con frecuencia.
- Si el repositorio es público, cualquiera puede abrir la app, pero nunca verá tus datos (están solo en tu navegador).
